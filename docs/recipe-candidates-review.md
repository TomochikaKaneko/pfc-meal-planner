# 料理候補50件レビュー

## 総評

50件は、洋食、焼き鳥・居酒屋、鍋、おでん、パン、コンビニ、発見枠を補う候補として有用です。DB登録前の方針としては、まず定番で食品DB追加が軽い料理を優先し、発見枠や専用食材が必要な料理は説明文とレシピURLを必須にして段階的に採用するのが安全です。

PFCに合うことと、料理として自然であることは別です。ハンバーグ、焼き鳥丼、キムチ鍋、寄せ鍋、豚しゃぶポン酢、ガパオライス、タンドリーチキン、ツナメルトトーストなどは自然度が高い一方で、フムス、ムサカ、クスクス、ソパ・デ・アホなどは実在料理ですが、説明がないと使いにくいため発見枠として扱います。
